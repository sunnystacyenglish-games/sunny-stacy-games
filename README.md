# Sunny & Stacy Games — 2.4.2 UI/UX polish

Локальное HTML/CSS/JavaScript-приложение. Существующие темы и изображения сохранены; backend не добавлен.

## Запуск

1. Распакуйте sunny-stacy-games-2.4.2.zip целиком.
2. Откройте терминал в папке sunny-stacy-games, где находится package.json.
3. С Node.js 18+ выполните `node serve.mjs`. Установка npm-пакетов не требуется.
4. Откройте http://127.0.0.1:4173. Не закрывайте терминал во время работы.

Альтернатива: `python -m http.server 4173 --bind 127.0.0.1`. Запуск через file:// не поддерживается. Используйте один адрес: localhost и 127.0.0.1 имеют разные браузерные хранилища.

## Основной сценарий

My Sets → New Set → имя и источник изображений → минимум 5 корректных слов и изображений → Save → Play → подготовка Dobble → Play.

Подготовка обязательна при входе через Hub, My Sets, редактор и прямую ссылку. В ней доступны набор, 1–4 карточки, режим представления, движение, тема, звук, автоматический следующий раунд и задержка ответа. Настройки запоминаются. Cancel не запускает игру. Settings доступны во время игры.

Параметр количества элементов убран из интерфейса и новых ссылок. Внутренняя плотность — максимум 6 элементов, дополнительно ограниченный размером набора и числом карточек. Все концепты продолжают участвовать в ротации. Legacy per/items в адресе игнорируются и не попадают в каноническую ссылку.

В mixed используются 1–2 карточки с совпадением строго слово ↔ изображение. В режиме одной карточки сохраняется обратная подсказка. Генератор гарантирует ровно один общий concept ID между карточками, независимые отвлекающие концепты и ротацию всего набора.

## Ссылки и импорт

Copy Game Link копирует ID реально выбранного набора и текущие mode/count/movement/theme/sound/autoNext/delay. Встроенный набор использует animals-1.

Явный set= в ссылке не заменяется автоматически. Если набора нет на устройстве, игра не запускается; предлагаются Import JSON и Choose another set. URL и остальные настройки остаются на месте.

Новые экспорты JSON содержат исходный set.id. Если при восстановлении ссылки импортирован именно запрошенный ID, он сохраняется и открывается подготовка. Другой JSON импортируется, но не подменяет запрос: нужно явно выбрать Use this set. Import another оставляет прежний запрос. Выбор другого локального набора тоже является явной заменой.

Обычный Import JSON в My Sets создаёт независимую копию. При импорте из missing-set экрана переносимый ID сохраняется, если он свободен. Существующие наборы не перезаписываются. Старый JSON без set.id можно импортировать, но для замены запроса нужно выбрать Use this set; определить старый ID по такому файлу невозможно.

## Изображения и проверка полей

Word требует текстовую лексику: emoji-only и pictographic-only значения недопустимы. Emoji требует Unicode emoji/pictographic content, включая составные emoji, оттенки кожи, флаги и keycaps; обычное cat недопустимо. Ошибки показаны рядом с полями. Некорректные концепты нельзя сохранить или использовать в игре. Старые структурно целые наборы остаются доступны для исправления; наборы меньше 5 элементов не запускаются.

Upload, paste и drop используют PNG/JPEG/WEBP. Изображения сохраняются как Blob в IndexedDB. HTTPS URL остаются ссылками; внешние сайты могут блокировать загрузку. JSON включает загруженные изображения в переносимом виде. GIF не поддерживается.

## Композиция и мобильный экран

Размеры назначаются гарантированными рангами и независимо перемешиваются на каждой карточке. Отношение крупнейшего и наименьшего ранга — 2.15. Базовые крайние размеры около 37–39% и 17–18% диаметра; в плотной композиции безопасная подгонка может пропорционально уменьшить всю иерархию. Очень длинные слова дополнительно подгоняются по ширине.

Повороты выбираются один раз: изображения до ±45°, слова до ±22°. Размерные ранги и углы сохраняются в течение раунда. Движение изменяет только позиции. Размещение перебирает ограниченное число кандидатов, учитывая измеренные повёрнутые AABB. Предусмотрены ограниченные этапы уменьшения и гарантированный безопасный fallback; бесконечных попыток нет.

Размер двух карточек рассчитывается из фактически доступной ширины и высоты после управления. На узком экране шапка компактнее. Обе карточки остаются круглыми; resize не пересоздаёт раунд и не сбрасывает счёт. При изменении размеров композиция может адаптироваться с прежними размерами-рангами и поворотами.

## Хранилище и версия

shared/sets.js — repository; shared/database.js — IndexedDB adapter, база sunny-stacy-content, store sets. Миграция не требуется. Настройки — localStorage; новые сохранения не содержат per/items. shared/content-rules.js отвечает за общую валидацию. games/dobble/config.js — единые правила для URL, подготовки и Settings; resolution.js отделяет явный запрос от необязательного remembered default.

Единственный источник номера версии — package.json → version. shared/version.js экспортирует APP_VERSION, shared/app.js показывает его на страницах и в диалогах. Будущая страница подключает shared/styles.css и shared/app.js.

## Ограничения

Облака и синхронизации нет. Для ссылки на пользовательский набор на другом устройстве нужен его JSON; одна ссылка не переносит контент. Очистка данных сайта удаляет локальные наборы — используйте Export JSON для резервной копии. Нет autosave; есть предупреждение о несохранённых изменениях. Проверки мобильных размеров выполнены в браузере, не на физических телефонах/ClassIn.

## UI/UX polish 2.4.2

В игре убрана верхняя панель. Навигация открывается за левый язычок: наведение мыши, касание или фокус клавиатуры. Внутри — главная, My Sets, Settings, Fullscreen, Copy Game Link и версия. Уход мыши закрывает меню через 400 мс; возврат отменяет закрытие, фокус внутри удерживает меню, Escape или касание вне закрывает. Меню накладывается поверх поля. Размер кругов ограничен реальной свободной шириной и высотой, без прежнего потолка 520 px.

Hub содержит доступные игры, Coming soon, компактный список дальнейших планов, My Sets, About и соцсети. Тексты About/intro и адреса соцсетей редактируются в shared/site-content.js. Все четыре URL пока пусты: Telegram, YouTube, Instagram, VK отображаются без ссылок. Для активации укажите проверенный HTTPS URL.

Бренд: текстовый wordmark + заменяемый shared/brand-mark.png (также есть исходный SVG). PNG используется для совместимости с простыми серверами. Новые игры могут подключать shared/game-shell.css и shared/game-shell.js и использовать разметку data-game-shell из Dobble. Содержимое nav расширяется обычными ссылками/кнопками. Место data-app-version заполняется shared/app.js; единственный источник версии — package.json. Без явного места индикатор остаётся в стандартном углу, как в редакторе.

Проверка вручную: откройте Hub → Play Dobble → Play. Наведите курсор на левый язычок, перейдите в панель и обратно; проверьте задержку закрытия. Откройте Settings, выберите 1/2/3/4 карточки. Включите движение и проверьте меню во время раунда. На телефоне откройте касанием и закройте касанием вне меню. Hub и Dobble проверены на 390×844, 412×915, 844×390, 915×412, 820×1180, 1024×768, 1366×768, 1920×1080.

Дополнительные тесты: tests/polish.html, tests/shell-motion.html; tests/regression.html последовательно запускает проверки хранилища, редактора, pre-game, версии, адаптивности и рендеринга. tests/mobile-preview.html — два мобильных предпросмотра. Тесты выполняются кнопкой Run.
