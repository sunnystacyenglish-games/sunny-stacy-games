# I Spy / Spot It — 2.12.0

## Запуск и проверка вручную

В папке проекта выполните `node serve.mjs` (Node.js 18+, без установки зависимостей), затем откройте http://127.0.0.1:4173/activities/.

1. Scene Editor → добавьте фон, изображения и расположите объекты.
2. Добавьте Targets: текст задания и один или несколько объектов-ответов. Один объект можно назначить нескольким Targets; неназначенные объекты остаются отвлекающими.
3. Save activity → Close → Play I Spy / Spot It.
4. В Content выберите сцену, в Gameplay — порядок заданий, звук ошибки и показ общего прогресса. Themes содержит общие тему и звук. Нажмите Play.
5. Проверьте неправильный ответ, правильный ответ, повторный клик и автоматический переход через 650 мс. Найденные объекты остаются на сцене. После последнего задания доступен Play again.

Прямой вход: http://127.0.0.1:4173/games/i-spy/. Ссылка с выбранной сценой использует `?activity=ID`. Она работает в браузере, где сохранена сцена. Для переноса используйте существующий Export/Import activity JSON.

## Реализация

- `games/i-spy/engine.js`: независимое состояние сессии; найденные ответы хранятся по Target ID и object ID. Перемешивание выполняется при создании сессии, исходные данные не меняются.
- `games/i-spy/activity.js`: регистрация игры для существующего типа `scene`, ровно три игровые настройки.
- `games/i-spy/game.js`, `index.html`, `game.css`: выбор сцены, игровой экран, звуки, анимации, переходы, повтор, ошибки и адаптивное отображение.
- `games/i-spy/settings.js`: локальные предпочтения и параметры ссылки.
- `shared/activity/catalog.js`: регистрация I Spy.
- `activities/index.js`: ссылки Play для совместимых игр через capabilities/content type. `activities/index.html`: уточнён вводный текст.
- `index.html`: карточка новой игры. `package.json`: версия и тест. `README.md`: запуск новой версии.
- `tests/i-spy.test.mjs`, `tests/i-spy.html`, `tests/i-spy-browser.js`: проверки новой игры.

Существующие IndexedDB activities/activityAssets и repository используются без изменения схемы. Runtime не сохраняет прогресс в авторскую сцену. Настройки хранятся отдельно в localStorage; недоступное localStorage не препятствует игре. Нет backend, аккаунтов или облака.

## Проверено

- Все 18 Node test suites из package.json прошли.
- Браузерный I Spy workflow: несколько ответов, неправильный/повторный клик, decoy, блокировка на переходе, автоматический следующий Target, many-to-many, завершение, replay, независимый звук ошибки и общий прогресс.
- Геометрия сцены на 1000×760, 768×1024, 390×700, 844×390 и 320×480: сохранены пропорции и относительные позиции, горизонтального переполнения нет.
- Невалидные Targets, пропавший object asset, отсутствующий фон, пустая сцена и неизвестный activity ID обработаны без падения.
- Сохранённая сцена побайтно не меняется при игре. Content Studio показывает ссылку совместимой игры.
- Enter активирует объект и увеличивает счётчик. Интерактивные объекты — native buttons; авторский порядок DOM сохраняет верхний объект при перекрытии.
- Shared setup browser checks для Dobble, Wordly, Tic-Tac-Toe и Story Dice прошли.
- Editor workflow browser checks: Bridge, Sentence, Deck, Scene, portable image export/import и повторное открытие прошли.
- Ошибок JavaScript в просмотренной browser console нет.
- Все 42 файла четырёх прежних игр совпадают с архивом 2.11.0.

## Ограничения

Проверки размеров выполнялись в браузере, без физического планшета/телефона и ClassIn. Звуковые проверки подтверждают вызов правильных существующих аудиофайлов; слышимость на конкретных динамиках не измерялась. Внешний image URL зависит от доступности сервера. При пропавшем изображении объекта остаётся обозначенная `?` область; фон, который не загрузился, не позволяет начать игру. Очень мелкие или полностью перекрытые объекты зависят от авторской композиции: игра не меняет расположение и не увеличивает hitbox за заданные границы.
