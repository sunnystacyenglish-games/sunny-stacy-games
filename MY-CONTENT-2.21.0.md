# My Content — Delta 8 · v2.21.0

## Архитектура и сохранность

До изменения Concepts и остальные материалы рисовали две отдельные библиотеки. Concepts находятся в IndexedDB `sets`, остальные документы — в `activities`; изображения последних — в `activityAssets`. Концептные загрузки остаются Blob-полями в существующих записях. Папки — `folders`, принадлежность Concepts — `setFolders`.

IndexedDB обновлена с версии 3 до 4 добавлением одного хранилища `activityFolders`. Оно содержит только `{id, folderId}`. Старые `sets`, `activities`, `activityAssets`, `folders` и `setFolders` не переписываются. Концепт и документ с одинаковым ID не конфликтуют: принадлежность хранится отдельно. Объединённый индекс создаётся только в памяти; авторские записи не дублируются и не конвертируются.

Старые связи Concepts сохраняются непосредственно, без переноса. Записи без связи относятся к корню. Неизвестная папка отображается как корень без исправления авторских записей. Удаление папки одной транзакцией возвращает её Concepts и документы в корень. Вложенности раньше не было, она не добавлена.

Дублирование Concepts использует прежний repository. Для остальных типов добавлены duplicate/delete в общий contentRepository: отдельный ID документа, независимая глубокая копия содержимого, сохранённые внутренние ссылки и ссылки на изображения. Общие изображения при удалении документа не удаляются. Старые колоды с шестью подколодами сохраняют все шесть при дублировании.

## Интерфейс и превью

Одна сетка: папки первыми, далее все типы вместе. Общая карточка содержит превью, название, тип, статистику и меню справа сверху. Нажатие на карточку открывает её существующий редактор. В My Content нет Play; редакторы и игровые меню не изменены. Built-in Animals 1 защищён от удаления; Edit a copy сохраняет прежнюю семантику.

- Concepts: первые четыре имеющихся изображения, emoji или реальные URL/Blob.
- Scenes: реальный фон, `object-fit: contain`, без обрезки и искажения.
- Card Decks: до пяти стопок с фактическими цветами колод.
- Bridges: фактические фрагменты первого задания, отмеченные пропуски.
- Sentence Correction: первая пара, прежняя функция sentenceDiff, зелёные/красные изменения и знаки ✓/✕.

Превью создаются при приближении карточки к видимой области через IntersectionObserver; изображения используют lazy loading и async decoding. Редакторы для отрисовки превью не монтируются. Пустые данные и отсутствующие изображения дают нейтральный fallback.

Меню: Edit, Duplicate, Export JSON, Move to…, Delete с подтверждением. Папки: Open, Rename, Change Color, Delete Folder. Стрелки/Home/End переводят фокус между действиями; Escape закрывает меню. Мышью карточки можно переносить за превью/название; Move to… доступен без drag-and-drop.

## Поиск, фильтры, сортировка

Поиск по названию без учёта регистра, с обрезкой пробелов, только в текущем уровне. Область поиска подписана. Фильтр охватывает пять типов; папки остаются видимыми. Состояние поиска/фильтра/сортировки сохраняется при навигации между папками в текущей странице.

Recently Edited, Recently Created, Name A–Z, Name Z–A работают совместно с поиском и фильтром. Папки сортируются отдельно и всегда идут первыми. Прежнее ручное перетаскивание папок сохранено; выбор сортировки возвращает порядок по выбранному критерию. Отсутствующие даты старых материалов не выдумываются: используется детерминированный порядок по имени/ID. Новым папкам присваиваются реальные даты создания/редактирования.

## Ограничения

Данные по-прежнему локальны в конкретном браузере и origin. GitHub-публикация кода не переносит личные материалы между localhost и GitHub Pages. Папки одноуровневые. Поиск не включает содержимое других папок. У старых Concepts нет createdAt: сортировка по созданию использует fallback, не фиктивную дату. Экспорт материала не включает структуру папок. Превью отсутствующего/закрытого внешнего изображения восстановить невозможно; показывается fallback.

Глобальный Dark Mode в текущей библиотеке не реализован; эта дельта его не добавляет. Используются текущие общие цветовые переменные приложения. Миграция проверена на старых сохранённых тестовых записях; это не обещание восстановления произвольно повреждённой базы.

## Локальный запуск

В каталоге sunny-stacy-games выполнить `node serve.mjs`, затем открыть http://127.0.0.1:4173/sets/ . Для тестов — `npm test` либо последовательный запуск Node-команд из package.json.

Проверка вручную: создать папку → меню материала → Move to… → повторить для разных типов → открыть папку → отфильтровать тип/название → открыть редактор → вернуться → Duplicate/Export → перезагрузить. Удаление папки должно вернуть материалы в корень.

Тест миграции требует отдельного origin на порту 4180 и ещё не обновлённой тестовой базы: сначала Create legacy fixtures and test migration, затем Run library checks. При повторном прогоне использовать только Run library checks; база не сбрасывается автоматически.
- tests/setup-menu.html: прежняя браузерная проверка Dobble, Wordly, Tic-Tac-Toe и Story Dice прошла: папки, временные исключения, minimum, вкладки, темы, мобильный layout и неизменный set ID. Консоль без ошибок.
